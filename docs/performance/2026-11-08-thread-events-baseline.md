# 跨线程事件功能的性能基线检查（2026-11-08）

本轮跨线程功能在已有主线程路径上引入了小幅固定开销：完整复核中多数图与状态场景耗时增加约 0.3%～1.7%；全局事件发布加派发的三组对比为 +3.39%、+1.72%、+3.37%。未发现可稳定复现的大幅端到端回退。共享串行图和背压 128 等待在一组复核中分别出现 +7.27% 和 +5.49%，后续定向 ABBA 为 +1.20% 和 +1.18%；异常轮次完整保留，不据此断言代码回退，也不排除小幅开销。

两个结果需要单独记录：getter 微基准耗时约翻倍，但每次只增加约 91 ns；相对 10 月 22 日优化基线，请求响应耗时累计增加约 28%，这是实际观察到的历史回退，不能以本轮功能对比基本持平掩盖。

## 基线与测量口径

- 本轮影响：`5049c7da099d73a190d02abaccce75a2dad526d4`（全局 post_event 已有，跨线程功能尚未加入）对当前工作区。
- 文档基线：`411c0e22e9f46520e407a8b7fc18116093055a73` 对当前工作区。独立解出的源码指纹与 [10 月 22 日报告](aduit-2026-10-22.md) 的优化后指纹完全一致。
- Python 3.12.12，macOS-27.0.1-arm64-arm-64bit；同一解释器、相同工作目录和依赖，GC 开启。普通日志和分发打印关闭，保留 ERROR。未固定 CPU 核心。
- 每组采用四个独立进程 `before → after → after → before`；每场景每进程预热一轮。首轮与历史组每进程测量 3 轮（每版 6 样本）；完整复核测量 7 轮（每版 14 样本）；定向复核测量 9 轮（每版 18 样本）。各组独立统计，不混合不同批次的绝对耗时。
- 原有四种图仍为 512 并发 × 16 节点，并行宽度 4；大状态和三档 sleep 负载沿用原报告。快照策略、输入输出隔离、背压和计时边界保持一致。
- 图总耗时包含建图、context/task 准备、执行和结果复制；校验、清理与分解在计时之后。事件发布场景计时到所有 handler 完成，另保存纯发布阶段耗时。请求响应使用主线程原生 wait_for_event，等待 processed 点。
- 每轮校验完整结果、状态、步数、快照数、事件顺序或响应关联；结束时排空分发任务并确认许可归还。源码指纹排除版本文件；每组各版本运行时指纹一致，四进程驱动指纹也一致。
- 定向复核补充进程 CPU 时间与 GC collection 次数；额外诊断取样放在图的壁钟计时边界外。选择 --scenario 时跳过独立内存测量。

## 微基准与内存

getter 定向复核包含 200,000 次循环与对象身份断言，结果为 95.50 → 186.00 ns/次（+94.78%，增加 90.51 ns）。首轮为 +100.53%，完整复核为 +92.56%，相对增幅稳定。新增主线程归属及 loop 校验会增加常量成本；本轮没有逐项消融这些检查，不能精确分配各检查的贡献。

## 对照 10 月 22 日优化基线

以下来自重新运行的同场 ABBA（每版 6 样本），没有直接使用历史报告里的毫秒数进行回退判断。两版本之间包含跨线程功能以外的历次变更。

请求响应累计为 194.63 → 249.14 ms（+28.01%），约 95.03 → 121.65 µs/往返，这是本次发现最明显的历史端到端回退。本轮新增功能的同场对比则为首轮 +1.85%、完整复核 -0.25%、定向复核 -0.20%；因此不能将历史 +28% 归因于此次跨线程功能。

源码检查确认：EventWaiter 和 wait_for_event 在 5049c7d 与当前工作区之间的 AST 完全一致；相对 411c0e2，等待实现已经演进为多事件收集、独立超时 Future、asyncio.wait 和 shield 等结构。可将等待路径列为后续专项性能审计对象；目前没有逐提交或逐机制消融，无法把全部历史差额归到某一项实现。

411c0e2 没有全局 post_event，故该场景记录为 unpaired，不伪造兼容实现参加历史对比。新增跨线程 API 的压力测试结果另作为功能基线，本报告检查已有主线程路径。

## 复现与数据

```bash
mkdir -p /tmp/apixis-pre-thread /tmp/apixis-documented
git archive 5049c7d src | tar -x -C /tmp/apixis-pre-thread

.venv/bin/python scripts/benchmark_runtime.py \
    --baseline-source /tmp/apixis-pre-thread/src \
    --output /tmp/pre-thread-comparison.json --repeats 7

    --scenario event/global-post --scenario event/request-reply --scenario event/getter
```
